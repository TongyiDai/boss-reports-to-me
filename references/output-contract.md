# 周报结构 · output-contract.md

周报**按人名分段**，直属上级在前、更上层在后（roster 已按 `直属上级 → +2 → +3 → +4` 排序）。
顶部一句总判断，每人默认用**幕僚四段**。发送前始终提示：可切换风格（下方三选一）。

## 通用骨架

```
# 📮 老板向我汇报 · 本周（8/18–8/24）

> 本周你的老板们在关注什么：<一句话总判断，抓最强的共同信号>

<高交集 leader 独立成段，见下方风格>

## 上层零星信号
<交集小的更上层合并成一段，每人一句话+来源；见文末>

---
覆盖：直属+N 位上层 · 数据来自你有权限可见的会议纪要/发言/文档 · 空缺已标注
```

规则：
- **证据与呈现按密度排序：会议纪要 > 消息发言 > 文档**（文档对上级链常无产出，有则补充、无则不凑）。
- 无可见动态的 leader 保留分段，写「本周无可见公开动态」，不臆造。
- 每条**原文**都带可点击来源 `[来源](url)` + 时间；纪要给会议名，消息给群名，文档给标题+链接。
- 观点/总结基于原文，不外推；拿不准就降级为「信号偏弱，供参考」。
- 相关性三重过滤：与你的工作/OKR 相关 > 决策或方向信号 > 纯事务性；只留前两类的高价值项。
- **密度分流**：单个 leader 本周可见证据 < 3 条且来源单一时，不单独成段，并入「上层零星信号」。

## 默认风格 · chief（幕僚四段）

结论先行，四段固定顺序：**总结 → 观点 → 原文 → 下一步**。像参谋跟你汇报。
原文部分按密度排序：**先会议纪要、再消息、最后文档**。

```
### 李硕（直属上级 · People CS）
📌 总结：本周把 Q3 重心从交付明确转向续费。
💡 观点：注意力从「签单」移到「留存」，下半年考核口径可能重排。
💬 原文：
  - 🎙 Q3 复盘会纪要："续费率下滑是下半年最大风险" — 8/21 · [纪要](url)
  - 💬 "先把头部客户的续费口径统一" — 8/22 项目群 · [来源](url)
  - 📄 《Q3 续费作战》· 8/22 · [链接](url)   ← 有才带，无则省
→ 下一步：把你手上的数字人方案提前挂到续费指标上。
```

## 可选风格 · sair（咨询备忘录）

每人四段：**情形（含原文）→ 分析 → 洞察 → 建议**。更正式、分析感更重，偏 MBB 备忘。

```
### 张三（直属上级）
**情形**：本周 3 条发言 + 1 篇文档围绕 Q3 续费。
> "续费率下滑是下半年最大风险" — [来源](url)
**分析**：从交付 KPI 转向留存 KPI。
**洞察**：下半年考核权重或重排，交付团队承压。
**建议**：提前把数字人方案与续费指标挂钩。
```

## 可选风格 · humor（轻幽默型）

同幕僚四段的信息量，口吻更轻松、带一点玩笑，但**不牺牲原文与来源的准确**。适合当作轻松晨读。

```
### 张三（直属上级）· 本周关键词：续费续费还是续费
📌 总结：老板这周满脑子都是"别让客户跑了"。
💡 观点：签单的高光时刻过去了，现在拼的是留人。
💬 原文（不是我编的）：
  - "续费率下滑是下半年最大风险" — 8/21 周会 · [来源](url)
→ 下一步：赶紧把你的数字人方案往续费上蹭一蹭，蹭对了就是功劳。
```

---

## 上层零星信号（合并段）

交集小的更上层（+2/+3/+4）常常全周只有几条、且集中在同一场沟通。不要为他们硬撑幕僚四段——
合并成一段，每人一句话 + 来源即可。全周 0 条则如实标注。

```
## 上层零星信号
- 武笑天（+2）：仅 1 场客户群沟通，5 条，围绕某客户交付节奏 · [来源](url)
- 林婵（+3）：同一场客户沟通，4 条，未见独立议题 · [来源](url)
- 其余上层：本周无你可见的公开动态。
```

判断规则：单个 leader 本周可见证据 < 3 条且来源单一 → 进本段；定期跑时这些层可降频（如每月一次）。

---

## 风格切换

- 默认 `chief`。用户可随时说「用咨询备忘录/SAIR」→ `sair`，「来个轻松点的/幽默版」→ `humor`。
- 切换即改：`python3 scripts/state.py set-schedule --style <chief|sair|humor>`，此后定期跑沿用。
- 每次成稿末尾附一行提示：`（当前风格：幕僚四段。想更正式→SAIR，想轻松点→幽默版）`。
